# RuleEnabled

Включено ли правило в проверки. Подпись поля на экране по-прежнему «Включено».

| Параметр | Значение |
|---|---|
| Java-класс | `com.digitilius.multireestr.entity.RuleEnabled` (`implements EnumClass<String>`) |
| Тип id | String |
| Урок | 6. Справочники и правила (шаблоны, версии, параметры) |
| Используется | [Rule](../entities/Rule.md).`enabled` |

## Значения

| Константа | id | Заголовок (ru) | Заголовок (en) | Примечание |
|---|---|---|---|---|
| `YES` | `YES` | Да | Yes | правило участвует в проверке по запросу и в плановом скане |
| `NO` | `NO` | Нет | No | правило не запускается |
| `EMPTY` | `EMPTY` | Не задано | Not set | правило не запускается |

Пустое значение в базе (колонка необязательна) тоже не запускает правило. У нового правила по умолчанию `YES`.

В проверку попадает только `YES`. Пробный прогон черновика это поле не смотрит: сравнивается выбранная версия.

Заголовки — в `messages_ru.properties` и `messages_en.properties` (`com.digitilius.multireestr.entity/RuleEnabled.YES=…`).
